## Colours in print

CMYK values for each colour in [colours.md](../01-foundations/colours.md). Only Magenta's value comes from the brand book. The rest are **placeholders**: they were converted from HEX using the standard macOS print profile (Generic CMYK), not chosen by hand. A designer or the printer must check them before anything is printed.

| Name | HEX | CMYK | Source |
|---|---|---|---|
| Magenta | `#FF1493` | C0 M100 Y0 K3 | Brand book |
| Dark grey | `#2D2D2C` | C80 M75 Y72 K45 | Placeholder |
| Mid grey | `#DFDCD1` | C11 M8 Y12 K0 | Placeholder |
| Off white | `#F0F1EC` | C5 M3 Y4 K0 | Placeholder |
| Yellow | `#FFFC5D` | C6 M1 Y58 K0 | Placeholder |
| Green | `#1AEA7B` | C45 M0 Y48 K0 | Placeholder |
| Blue | `#61B5FF` | C48 M20 Y0 K0 | Placeholder |
| White | `#FFFFFF` | C0 M0 Y0 K0 | No ink (paper white) |
| Black | `#1B1212` | C68 M74 Y64 K75 | Placeholder |

Things to check when confirming them:

- Yellow, Green and Blue are brighter than print ink can reproduce, so they will print duller than they look on screen.
- Dark grey and Black are rich four-ink blacks. They suit large areas, but small text may need to be black ink only (K100).
- Off white is a very light tint that can look patchy. An off-white paper with no ink may work better.
