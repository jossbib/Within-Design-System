## Logo versions

| Version | When to use | File |
|---|---|---|
| Full colour | **Primary. Use it by default**, on Off white, White and light photos. | [SVG](../assets/logos/within-logo-colour.svg) · [PNG](../assets/logos/png/within-logo-colour.png) |
| White | On Magenta, Dark grey, Black and dark photos. | [SVG](../assets/logos/within-logo-white.svg) · [PNG](../assets/logos/png/within-logo-white.png) |
| Black | Where only one colour is possible on a light background, such as one-colour print or a black-and-white document. | [SVG](../assets/logos/within-logo-black.svg) · [PNG](../assets/logos/png/within-logo-black.png) |
| Magenta | Rarely used. | [SVG](../assets/logos/within-logo-magenta.svg) · [PNG](../assets/logos/png/within-logo-magenta.png) |

Use only these four files. Don't recolour the logo or rebuild it from type.

## Clear space and minimum size

**Clear space:** leave at least **half the logo's height** empty on every side, with no text, edges or other graphics. The logo files have no padding built in, so measure from the edge of the square bracket. On slides, leave the full height of the logo (see [layout-rules.md](../02-presentations/layout-rules.md#logo-placement)).

**Minimum size:**

| Where | Smallest width |
|---|---|
| Slides | 1.97 cm (about 56 pt) |
| Screen | 80 px |
| Print | 20 mm |

Measure the width from the left edge of the "w" to the right edge of the "n".
