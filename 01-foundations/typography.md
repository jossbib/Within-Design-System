# Typography

The brand fonts and how to set text.

> **Status: started.** Fonts are taken from the font slide in the [brand book](https://docs.google.com/presentation/d/10adt0hE1NL03DJu31Li8YJrdnTZbtgfCTYKqPR8RuIU/edit). Fallback fonts are set; text styles and rules are still to be added.

## Fonts

| Font | Used for |
|---|---|
| Proxima Nova Bold | All titles and headings |
| Gelasio | All paragraph text and small print |

Proxima Nova is available from [Adobe Fonts](https://fonts.adobe.com/fonts/proxima-nova). Gelasio is free from [Google Fonts](https://fonts.google.com/specimen/Gelasio), in all weights.

## Fallback font

Use these only where the brand fonts can't be loaded, for example a PowerPoint file opened on a computer without them, or an email.

| Brand font | Fallback |
|---|---|
| Proxima Nova Bold | Arial Bold |
| Gelasio | Georgia |

Georgia is the fallback for Gelasio because Gelasio was drawn to match Georgia's letter widths, so text takes up the same space and doesn't reflow.

Google Slides includes both brand fonts, so the WITHIN Slides template never needs a fallback. Don't swap fonts to make text fit.
