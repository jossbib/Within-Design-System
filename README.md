# WITHIN Design System

WITHIN's design decisions, written down as plain text files that both people and AI tools can read.

> **Status: early outline.** This is a first sketch of the structure. Most sections are placeholders showing what is likely to go where. The folders, files and headings may change as the project develops.

## What this is

The brand book in Google Slides shows what the brand looks like. These files describe the same rules in words, so that:

- anyone on the team can look up a colour, font or layout rule quickly
- the rules can be pasted into (or read by) an AI tool, so the slides it builds stay on brand
- there is one place to update when something changes
